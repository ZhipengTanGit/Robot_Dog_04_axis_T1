机器狗主板 USB 焊接调试包使用说明

适用 Windows 10/11 x64。app、runtime 已含程序、Python 和串口依赖，无需安装 Python、连接 WiFi 或准备 Ubuntu。请完整解压到可写目录，保留文件夹结构，不要在 ZIP 内运行。

1. 连接与启动
用 USB 数据线连接主板 CH340 数据口与电脑，双击 start.cmd。程序自动寻找 CH340；多个端口时按提示选择。未发现端口时，检查数据线、接口和设备管理器中的 CH340 驱动。本包附“CH340-官方驱动下载”入口，缺驱动时从该官网安装（驱动安装可能需要管理员权限），本包未内置驱动安装程序。list-ports.cmd 可列出串口；也可在命令行运行 start.cmd --serial-port COM7 指定实际端口。若串口被占用，关闭其他串口调试程序。网页默认 8081，被占用时自动选择空闲端口，以启动窗口显示并打开的地址为准。

2. I²C 扫描
点击 I²C 扫描并等待结束。扫描 ESP32 共享总线：SDA=GPIO8，SCL=GPIO19。
预期地址：0x20 XL9555 扩展器；0x10 或 0x11 ES8388 音频芯片；0x3C OV5640 摄像头；0x5A 触摸控制器。
地址应答只证明有器件响应；无应答需检查焊接、供电及连接。若偶发其他未知地址，请重复扫描核实，不要凭一次应答确定器件型号。不包含 STM32 总线上的 IP5310、AHT20。

3. 摄像头检查
点击摄像头检测，依次查看 RESET/PWDN 控制位、0x3C 应答、芯片 ID、初始化和 JPEG 取帧结果。只有取得并校验真实 JPEG 才判定可用；USB 模式不显示摄像头画面。控制位读回不能证明供电电压或外部 24 MHz 时钟实测正常。补焊、插拔或调整 FPC 前必须断电，确认触点方向正确后再上电，用新检测确认结果。

4. 麦克风试听
ES8388 无应答时先跳过。补焊后重新上电，让音频芯片重新初始化。就绪后点击网页开始试听，对板载麦克风说话，声音由电脑播放，无需连接主板扬声器；请确认电脑音量并按浏览器提示允许播放。结束时点击停止试听。

5. 交接参考状态与电池说明
本次交接时 0x20 正常应答，0x3C 和 ES8388 未应答，屏幕未连接；以维修后的新检测结果为准。电池名义充电设定保留 1850 mA，焊接排查期间请勿随意更改。名义设定不代表实测电流；电池电压、实际充电电流尚未采样，电池 NTC 未连接，显示无数据不等于零，环境温度也不等于电池温度。

6. 结束与反馈
双击 stop.cmd，或在运行控制台按 Ctrl+C，停止本包服务并释放串口。仅关闭浏览器不会停止服务。排查时可发回 data 目录和故障现象；调试日志不保存录音。

本包为电脑端工具，主板已烧录对应程序，不需要再次烧录。已在开发电脑将 ZIP 解压至中文空格目录、使用包内运行环境实测串口数据和两种扫描；工程师电脑仍需有可用的 CH340 驱动。
