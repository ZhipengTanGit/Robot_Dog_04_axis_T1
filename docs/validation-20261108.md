# 2026-11-08 小智外设整合版与 STM32 R23

小智已从纯语音应用扩展为机器狗外设应用：板载温湿度读取、屏幕动态表情和身体动作通过 MCP 提供给语音服务。用户已确认语音对话、温湿度播报、屏幕变化及短动作测试正常，并授权发布源码。

## 源码与配套关系

- `ESP32-IDF-Xiaozhi`：Xiaozhi 2.1.0 / ESP-IDF 5.4.4，外设适配 r2，16 MiB Flash / 8 MiB OPI PSRAM。
- `STM32-LSP-Debug`：已实机烧录的 `stm32f103rb-action-teach-20261107-r23` 快照；现有四方向步态与 PET3 摸头动作、异步 UART3 日志、115200/117647 TTL 反馈适配。
- 屏幕沿用已验证的 CO5300 QSPI、横屏旋转、双像素对齐、TE 同步与 DMA 排空逻辑；I²C 共享锁覆盖音频、触摸和扩展器原子读改写。
- STM32 无已保存设置时仍默认 350 mA，现存设备 NVS/设置不发布。充电名义档位不等于实测电流。

本次只发布外设整合与配套固件，保留原七模块目录。仿真开发工作另行整理。

## 当前边界

小智版暂不包含摄像头和旧调试网页服务；握手轨迹未部署到该 STM32 版本。停止是释放扭矩，回中是限时保持。新板的供电、舵机方向与结构仍需要自身校验。

个人 Wi-Fi 文件、设备账户状态、Flash/NVS 备份、原始对话日志、构建缓存与含个人配置的镜像不上传。公开构建首次使用官方热点配网并绑定自己的账号。
