# 用户网页

公网入口：https://110.42.234.162/robot-studio/

本目录执行 `npm start`，打开 http://127.0.0.1:8093/ 。也可在 Windows 双击 `启动配色工作台.cmd`。依赖已随 dist 提供，无需 npm install。详细操作见 [使用说明](使用说明.txt)。

`dist/` 保留用户网页及历史 2026-10-29 公共固件下载，STM32 下载包仍为 PWM 测试版，不用于当前 TTL 舵机。当前固件源码见仓库 `ESP32-IDF-Debug/` 和 `STM32-LSP-Debug/`，本地调试终端见同级 `Debug-Terminal/`。

推送此仓库不会自动部署公网服务器。网站部署凭据和原机械 CAD 输入不随仓库发布；原模型资源、校验工具和第三方许可保留。
