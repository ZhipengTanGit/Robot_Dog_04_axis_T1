四足 / ROBOT WORKBENCH — 配色、装配与动作工作台

打开方法
1. 保留整个项目文件夹，不要只复制网页文件。
2. 双击「启动配色工作台.cmd」。启动器会检查本地服务，然后在默认浏览器打开网站。
3. 本地地址：http://127.0.0.1:8093/
4. 服务已经运行时，再次双击会直接打开现有网站。关闭浏览器不会停止后台服务；电脑重启后再次双击即可。

公网服务器访问
· 地址：https://110.42.234.162/robot-studio/
· 工作台独立登录，账号和密码均为admin；原服务器其他页面的登录保持原样。仅打开这个网址不需要本机运行Node.js。
· 配色、装配、爆炸图、编舞和3MF导出均在浏览器运行。不同网址的本地方案独立；可导出配色/动作JSON，再到公网网址导入。
· 服务器静态目录：/var/www/robot-dog-studio/current；版本保存在同目录的releases/，Nginx片段为/etc/nginx/snippets/robot-dog-studio.conf。
· 网页仅发布dist/，另安装本机回环认证服务；未上传CAD工程、凭据或本地诊断资料。部署及校验记录位于review-output/public-deploy/。
· 更新部署使用tools/deploy_public.py；传入现有私密交接目录的--handoff参数，使用工作台表单登录。当前电脑可用py -3.14运行，凭据只在内存中读取。

硬件测试与固件下载
· 顶部「硬件测试」打开独立页面；公网地址：https://110.42.234.162/robot-studio/hardware.html，本地地址：http://127.0.0.1:8093/hardware.html。
· 沿用工作台登录，提供 ESP32-S3 N16R8 的 ESP-IDF 5.4.4 公共测试包，以及 STM32F103RBT6 的 BIN / HEX。均针对 V0.24 主板；会替换当前程序。
· 桌面 Chrome / Edge 可直接选择本机 USB 设备烧录。ESP32 使用 CH340 串口；STM32 使用 ST-LINK/SWD。浏览器无法访问 ST-LINK 时，下载 BIN/HEX 使用 STM32CubeProgrammer，BIN 地址为 0x08000000。
· 关闭占用 CH340 的旧监测服务后，选择 USB 串口，以 921600 / 8N1 连接 ESP32；它负责桥接 STM32 数据。云服务器不访问用户电脑的 COM 口。
· 可手动测试 I²C、OV5640 检测与单帧抓拍、板载麦克风试听、扬声器、蜂鸣器、四路舵机、LED，并查看环境温湿度、按键、屏幕/TE/触摸与电池状态。
· 公共版不含私有 Wi-Fi/服务器配置、不自动联网；STM32 默认且最高名义充电档为350mA。上电不自动转动或发声；切后台/掉线后不重放舵机指令。
· 文件 SHA-256、适用型号与编译/实板验证状态均在页面列明。此公共版本已完成编译和模拟测试，实板烧录及外设联测仍需现场验证；详细说明可从页面下载。

机壳、腿部与原有内部元件由 SolidWorks 装配模型转换。补充的摄像头、扬声器和电池为有来源标注的装配参考外形。
可以分别修改身体骨架、上盖、电池仓、屏幕框、摄像头座、屏幕包角、腿部上段、腿部下段、脚端、腿部饰条、电源按钮、顶部功能按钮与四根外部立柱，共13个部位。
模型保留原来的逐面灰色和红色；PCB、屏幕、舵机等功能部件保持固定外观。
内部元器件可以显示，顶部「透视外壳」可看清内部件。「显示内部件」可控制它们是否出现；装配指导中由步骤自动决定显示状态。
页面的字体、Three.js、图标和模型资源都在本地，运行时没有外部网络依赖，无需修改防火墙。
本地服务需要 Node.js。本机使用 C:\Program Files\nodejs\node.exe；若更换电脑或安装位置，可修改 tools\start-local.ps1 开头的 NodePath。

如何配色
· 公网版从 https://110.42.234.162/robot-studio/ 进入登录页，工作台账号和密码均为 admin；右上角「退出登录」结束本次会话。本地8093预览不要求登录。
· 「按区域」模式下点击模型或右侧部位名称，修改所选部位的颜色。
· 「电源按钮」只调整侧面的独立电源按键；「顶部功能按钮」调整顶部四枚功能延长键，两组可分别配色、保存和导出。
· 「机身外立柱」覆盖两侧共四根加强肋的跨层外侧面、端面、根部倒角及柱顶/底帽；内部插舌、腔壁和螺孔保留其所属机身区域颜色。
· 「正在编辑」卡片显示当前区域或单面编号；选中项带有「编辑中」标记。模型以橙色实线标出选区，淡虚线提示被遮挡的部分。
· 点击右侧部位名称会自动定位模型；点击模型选面保留当前视角。卡片的「定位」按钮可再次查看选区；下方视角按钮可回到整体视图。
· 「单个面」模式下点击模型表面，只修改所选的一个面；可清除当前面或全部单面覆盖。
· 单面颜色优先于部位颜色；清除单面覆盖后，会恢复部位颜色或该面的原始CAD颜色。
· 「还原模型配色」清除部位和单面的颜色覆盖，恢复原来的红色包角、腿部饰条及各面灰色。
· 点击颜色块打开系统取色器；也可输入 # 加 6 位 HEX 色值，再按回车或勾选按钮应用。
· 六组预设：苔原、极地白、深海蓝、奶油橘、石墨黑、莓果紫。
· 可切换哑光、缎面、亮面，以及浅灰、暖白、深色视窗背景。
· 拖动旋转，滚轮缩放；也可使用立体、正面、侧面、俯视按钮、重置视角和自动旋转。
· 系统开启「减少动态效果」时，自动旋转保持关闭。

3D 装配指导
· 顶部切换「装配指导」，选择步骤或使用「上一步 / 下一步」。
· 共25步，从单独电池仓开始，逐块放入电池，再装骨架和四路舵机；电源按钮在主板之前从机壳内腔向外推出。屏幕与前框先在桌面预装，再整体从前方装入。
· 四枚延长键在高位、离体的上盖内侧预装：从上盖下方向上推出就位，再保持键与上盖的相对位置，将五件作为总成共同合拢。
· 四路腿部各分两步：先安装十字舵盘，再安装对应腿部；两件仍属于同一个编舞关节。
· 两块802440P参考电池为43×24×7.5mm，已包含显示标签厚度，按电池仓实际托底面放置。原电芯规格仍以厂家资料为准。
· 当前零件会高亮并演示装入方向；「重播本步安装」可重复观察。此前装好的部件会保留，后续部件不会挡住当前安装过程。
· 已装好的外壳会自动半透明，便于查看内部元件的安装；当前安装件保持不透明并高亮显示。
· 支持围绕模型自由旋转，从不同方向观察立柱、主板、摄像头、电池、扬声器和四腿的相对位置。
· 不绘制连接线。补充内部件的模型来源与参考尺寸见页面「模型来源与安装说明」。参考外形和安装动画用于位置指导，不作为加工图或装配公差依据。
· 原 CAD 的舵机与孔壁有约 0.05 mm 局部重叠；另有部分原 CAD / 补充参考件包络重叠。网页保留原定位，不通过移位掩盖，安装高度、尺寸和配合请以实物核对。

装配爆炸图
· 顶部切换「爆炸图」，用「展开距离」滑块查看每层结构，可播放展开或还原到完整装配。
· 展开后可点击「适配当前展开视图」，重新把全部零件放入视窗；仍可拖动旋转、缩放、导出 PNG。
· 展开路径为结构展示使用，不表示实际拆卸行程或螺丝尺寸。

四轴动作编舞
· 顶部切换「动作编舞」，四腿控件为紧凑的2×2布局。每条腿都有独立「回中」，只将该腿设为90°；「全部回中」同时恢复四腿。
· 可直接拖动模型腿部调整角度，或使用滑块/数字输入；拖动空白处旋转视图，Esc取消本次腿部拖动。
· 四条腿统一使用机身方向：90°为原装配姿态，增大角度向机头前摆，减小角度向后摆。0–180°为逻辑关节角；真机还需标定电机方向与安全行程。
· 调好姿态，设置到达它所需的时间（0.2–30秒），点击固定工具条的「添加为新帧」。最多60帧，关键帧列表可独立滚动，保存按钮始终留在调节区下方。
· 点击列表中某帧可编辑；角度或时长改变后会显示「未保存姿态」，点击「保存选中帧」才覆盖该帧，也可「添加为新帧」保留原帧。
· 当前姿态未保存时，播放、导出、切帧等会先提示保存，避免静默忽略刚调好的动作；若确实不需要这些修改，可点击「放弃修改」或「放弃并…」。
· 播放从 90° 中位平滑进入第一个关键帧，随后依次到达其他姿态。支持暂停、继续、进度条定位、停止回到中位。
· 勾选「循环」后，末帧会平滑连接下一轮的首帧。初始状态不自动运动，切换工作页面或进入浏览器后台会暂停动作。
· 可载入「四足打招呼」示例，示例同样需要手动点击播放；载入后可通过提示中的「撤销」恢复先前动作。
· 展开底部「动作文件与名称」，可以修改名称、保存到当前浏览器或导出角度JSON。文件包含各帧四脚角度与时长，可重新导入网站播放。
· 字段映射：frames 为关键帧数组；angles.frontLeft = 左前腿、frontRight = 右前腿、rearLeft = 左后腿、rearRight = 右后腿，角度单位为度；duration 为该帧用时，单位为秒。
· 当前只输出角度文件并在网站回放；直接输出固件留待后续接入。动作 JSON 与配色 JSON 是两种文件，不相互混用，也不会向真实舵机发送指令。
· 导入仅接受本工作台格式的 JSON，最多 200 KB、60 帧，严格检查四路角度和时长。
· 新动作文件为version=2、angleConvention=body-forward-v1，表示四腿统一的前后方向。旧version=1文件/本地动作会自动转换右腿角度以保留原视觉动作；旧文件与本地旧版备份保持不变，保存新版时使用独立存储项。

保存与导出
· 「保存方案」保存在当前浏览器，最多 8 个，可在「我的方案」中恢复或删除。删除后可立即撤销。
· 清除浏览器数据、使用无痕窗口或更换浏览器，可能无法找回本地方案。需要长期保留或传给他人时，请导出 JSON 文件。
· 「导出图片」保存当前真实三维视窗的 PNG。模型尚未载入成功时，按钮不会启用。
· PNG与3MF导出不包含选区的编辑高亮标记。
· 「方案文件 → 导出 JSON 方案」保存部位与单面颜色、材质、背景与所选标准视角。
· 「方案文件 → 导入 JSON 方案」恢复本工作台导出的文件；只接受字段合法、大小不超过 2 MB 的 JSON，最多5000个单面颜色。兼容此前的三色、五色、11部位和12部位方案；旧方案的按钮颜色会同时继承到电源按钮与顶部功能按钮，原有单面颜色保留。导入后如需保留，请再点击保存方案。
· 旧方案中已设置的上盖单面颜色会继承到从该面拆出的立柱帽；新版方案可独立清除立柱帽的单面颜色，导出后再次导入仍保持清除结果。
· 不同网址下的浏览器本地方案相互独立，可通过 JSON 在本地版与在线版之间转移。
· 「方案文件 → 导出已上色 3MF」生成 Bambu Studio 使用的结构件文件，保留当前部位色、单面颜色与耗材颜色分配；主板、屏幕、舵机、摄像头、扬声器、电池等非打印件不会导出。
· 3MF 用于在 Bambu Studio 中打开后切片。选择实际打印机与耗材、核对零件摆放、支撑和耗材颜色，再执行打印。导出操作不会直接向打印机发送任务。
· 3MF初始预设为X1 Carbon / 0.4mm / Generic PLA / 0.20mm，打开后请切换到实际机型和材料。当前最多16种耗材色，颜色数超过实际多色系统槽位时，需要自行重新分配。

启动问题
· 如果提示 8093 端口被占用，请确认占用它的程序后再处理。启动器不会强制关闭其他服务。
· 如果模型未载入，请保留 dist/assets 与 dist/vendor 目录，检查项目是否复制完整，再点击重新载入。
· 本地服务日志位于 review-output 文件夹中，以 local- 开头，便于排查启动问题。
· 不要直接双击 dist/index.html：三维模型需通过上述本地 HTTP 服务读取。

颜色与质感用于外观搭配预览。屏幕呈现受显示器、灯光与材质渲染影响，实际生产颜色请以实物色板为准。
