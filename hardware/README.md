# 硬件设计资料

本目录汇总找到的原理图、BOM、网表、原生 EDA 工程和芯片/模块手册。仅整理现有文件，没有修改电路或重新执行 ERC/DRC。

| 目录 | 内容 |
| --- | --- |
| `schematics/V0.24/` | 2026-10-19 导出的九页原理图 PDF、逐页 SVG、BOM 和网表 |
| `eda-source/` | 找到的嘉立创EDA 原生 `.epro2` 工程，保留原文件名 |
| `datasheets/components/` | 已整理的芯片数据手册 |
| `datasheets/display/` | AMOLED、触摸及显示模块参考资料 |
| `datasheets/modules/` | OV5640、舵机外购件与 TTL 协议说明 |
| `datasheets/reference-archive/` | 历次审核中收集的补充手册，按内容去重 |

原生工程的文件名日期为 2026-10-12，尚未验证它与 V0.24 导出及当前实物逐项一致。明确版本的查阅入口为 `schematics/V0.24/`。补充手册含历史选型和替代器件，例如 STM32F407 文档不能当作当前 STM32F103RB 的型号依据。

厂商手册保留原始内容与文件名，权利归各资料提供方；第三方副本、修订版本和型号需结合原文核对。TTL 协议中的通用角度范围不代表当前舵机版本，当前软件按用户确认的 0–180° 映射。

来源相对路径、文件大小和 SHA-256 见仓库 `docs/source-manifest.json`。历史整包、重复手册、演示视频、屏幕大型例程与临时审核截图未上传。
